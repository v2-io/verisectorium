## What differed
Much denser than predicted, and the vocabulary I guessed was mostly wrong in the particulars. "Compiler stages" is Joseph's own frame: no bespoke manual implementation yet, so don't lean on a recursively bootstrapped one; stage 0 is hand-written definition files that v2 reads, stage 1 v2 checks them, stage 2 the definition is itself records. "Four layout-bound segments re-cut" are four verisectorium *theory* segments (def-verisectorium's nine organs, def-atom's slug=identity, form-slug-form-kinds, form-process-map) whose principle is kept and whose layout is demoted to a rendering or importer dialect. Not ASF segments at all.

§7 is the part I care about. The spine as of 11-04:
- every record has content, what it *claims* (declared form/register/scope), and what its trail has *established* (computed standing per dimension); adjudication starts from the claimed/established mismatch and repairs by securing, revising, or (last) lowering the claim. That ordering is strengthen-before-soften made into a store rule.
- four decision kinds by *what they are about*: domain / interior / work / system.
- aspects (values whose basis is evidenced, decided, or attested) vs attributes (deterministic measurements that never go stale); rules band attributes into aspects; a graduation ladder (label → ruled → procedural → reified) that any aspect climbs only on demand.
- stability as a fixed point; perturbation opens an episode; a breaker halts runaway ripple and routes to a council; the monotone rule as a *working assumption* (rules only lower/reset/flag; only minds raise), with Joseph's counterweight that coupling/cohesion trade off and an optimizer-style run would replace it.

I predicted "unit of fate" would be lurking as "segment"; it is actually `def-atom`'s "one unit per fate", and the re-cut moves identity to a maintained binding. So the atom concept predates this note; the index said 05/06 replace the unit of fate with atoms-and-templates, which now reads as a *refinement* of an existing atom notion, not its introduction.

## Wander
The claimed/established mismatch is a very clean generator. It also quietly contains the value question: "established" is "computed standing on each dimension", which presumes dimensions have computable standings. The index's transcript-only exchange ("almost all an act+judgment machine") is going to press exactly here: is standing computed, or is it just the record of acts? The aspects/attributes split is a first answer (attributes computed, aspects warranted), and graduation says warrant is only reified on demand. I expect this triple (content / claimed / established) to survive in some form and the aspect-attribute machinery to get simplified.

The monotone rule is worth holding onto: it is the one place this note states an actual theorem-shaped property (finite ladders + one-way rules ⇒ fixed point), and it says explicitly not to promote it to a constraint.
