# core praxes

The canonical projection of this verisectorium's praxes: what is expected of a mind working on `core/` that no tool here enforces. A praxis is the dual of a CLI affordance: where the engine can embed a discipline deterministically it does, and what remains, how to orient, which surface to write in, when to call a cold read, is written down for the mind as a praxis. Each row is a `praxes/` segment. Marks as in `model.outline.md`; a provisional praxis is a suggestion about practice, true as stated.

| mark | def | praxis | description |
|---|---|---|---|
| provisional | present | [[praxes/working-on-core\|Working on core]] | The one procedure every mind touching `core/` follows: orient, change in the right surface, run the gate, log, commit; what provisional means here and who decides; when a word becomes a term; when to launch a cold read. |
| gap | – | releasing a decision | How a def goes from provisional to decided between steward and lead, and what is recorded. Not yet needed; nothing is decided. |
