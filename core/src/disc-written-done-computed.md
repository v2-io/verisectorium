# Written, done, computed

| | What | Who sets it | How it changes |
|---|---|---|---|
| **written** | a veritoid's content, its assertions, its references; a segment's assembly (which veritoids, in which slots, in what order); a projection's members; a segment's history, where its kind has a slot for it | an author | only by a segment changeset |
| **done** | acts: who did what, against which versions, answering which dimension, with what outcome | an actor, at a moment | appended, never edited; corrected by a later act |
| **computed** | every warrant; whether each reference holds; the frontier; whether a state is a steady state; every attribute and roll-up; each segment's inbox | the verisectorium, as of a state | by recomputation, never by anyone |

The inbox is in none of the three rows: it is influx bearing on a segment, outside its written state, with no standing, drained rather than kept. Acts are the input both sides answer to. A typed status word is a written thing wearing computed clothes; the whole discipline is the line in this table.
