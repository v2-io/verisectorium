# verisectorium

The verisectorium and its engine, vsect, begun afresh on 2026-11-04 (Joseph's decision: "new ideal vsect from the beginning, which can draw on anything principled from prior efforts").

Nothing here is built yet. The earlier work, with its full git history, is in `.archive/` as influx:

- `.archive/prior-incarnation/` is the verisectorium as it grew inside the Archema program repo (`arch`, `firmatum/verisectorium/`, 2026-08-05 to 2026-11-04). It holds the theory store, its SOPs, and RC1 (`theory/influx/segments-model-rc1/`), the model the new work starts from.
- `.archive/prior-vsect/` is vsect 0.1, the first working tool (`arch`, `firmatum/utils/vsect/`, 2026-10-30 to 2026-11-04): its Rust source, README, the agent-identity design, and the kernel drafts.

The preparation and discussion for the new work happens in `~/src/aat-v3/preparations/`.
